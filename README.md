# 6.1. Основы тестирования

Небольшой проект на JavaScript и React. В заказе сначала одна чашка кофе за 150 ₽. Кнопка «Добавить чашку» увеличивает количество и пересчитывает итог.

Тесты автоматически проверяют ожидаемое поведение. Если при правке формулы или кнопки итог станет неверным, Vitest покажет, какой сценарий сломался и какое значение получилось.

## Запуск

Нужны Node.js 22.13+ из ветки 22 или Node.js 24+ и npm. Выполните команды в папке проекта.

```sh
npm ci
npm test
npm run dev
```

Откройте адрес, который покажет Vite, и нажмите «Добавить чашку». Команда `npm test` запускает тесты один раз. Чтобы они перезапускались при сохранении файлов, в другом терминале выполните `npm run test:watch`.

## Разберите готовые тесты

1. Откройте [calculateTotal.test.js](src/calculateTotal.test.js). `test` задаёт имя сценария и функцию, которую запустит Vitest. Вызов `calculateTotal(150, 3)` даёт фактическое значение, а `expect(total).toBe(450)` сравнивает его с ожидаемым. Функция получает цену и количество, поэтому её можно проверить отдельно от React.
2. Откройте [CoffeeOrder.test.jsx](src/CoffeeOrder.test.jsx). `render` добавляет компонент в тестовый DOM, а `screen.getByRole` ищет элементы по роли и доступному имени. `<output>` имеет роль `status`, и в этом примере его имя задаёт `aria-label`. `toHaveTextContent` проверяет текст внутри элемента. В `/^150 ₽$/` знаки `^` и `$` обозначают начало и конец строки, поэтому проверяется весь текст.
3. Прочитайте тест клика. `userEvent.setup()` создаёт объект для действий пользователя. `await user.click(addButton)` дожидается завершения клика, после чего тест проверяет новый итог в DOM.

Строка `@vitest-environment jsdom` включает тестовый DOM для файла с компонентом. `afterEach(cleanup)` удаляет отрендеренный компонент после каждого теста, чтобы следующий начинался с пустого DOM.

## Попробуйте сами

1. **Прочитайте падение.** В [calculateTotal.js](src/calculateTotal.js) временно замените `price * quantity` на `price + quantity`. Выполните `npm test -- src/calculateTotal.test.js`. Найдите в отчёте имя теста, ожидаемое значение `450` и полученное `153`. Верните умножение и убедитесь, что тест снова проходит.
2. **Напишите тест функции.** Добавьте в `calculateTotal.test.js` сценарий для нуля чашек. Сначала запишите в названии ожидаемое поведение, затем вызовите функцию с ценой `150` и количеством `0` и проверьте результат.
3. **Напишите тест компонента.** Добавьте в `CoffeeOrder.test.jsx` сценарий с двумя кликами. Найдите кнопку по роли и имени, выполните два вызова `await user.click(...)` и проверьте, что итог равен `450 ₽`.

К концу практики попробуйте объяснить своими словами, что проверяет тест вычисления и что дополнительно проверяет тест клика.
